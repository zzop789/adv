# 可视化流程编辑器

编辑器用于本地制作剧情，入口是开发窗口，不随玩家便携包交付。它编辑 `story.json`；视频和 UI 仍归作品目录管理。

## 打开与制作

1. 执行 `npm run dev -- --game demo`，新作品替换为自己的 ID。
2. 点击“制作预览”中的“流程编辑器”。打开时暂停正在播放的视频，关闭后只恢复仍兼容的原播放。
3. 左侧添加视频、选择或结局节点。点击画布节点，在右侧修改视频素材 ID、文案、选项和下一节点。
4. 在“下一节点”或选择项的目标下拉框中连线，画布同步显示方向箭头。拖动节点调整排版，用加减按钮缩放，滚动查看画布。
5. 点击“校验剧情”，修复错误后“保存剧情”，或直接“预览未保存草稿”。预览成功临时收起编辑器；再次打开可继续修改同一草稿。

视频下拉来自 `assets.json`。先把文件放到 `games/<ID>/media/`，增加素材映射，再在编辑器中“重新读取”以刷新列表。UI 文件仍在 `games/<ID>/ui/`，具体修改见 [新建游戏教程](new-game-tutorial.md)。

## 编辑与历史

编辑器允许暂时空文案、未连线、孤立节点等中间状态。保存或预览时才要求整个剧情可以运行。节点 ID 为稳定标识，新节点自动生成不重复 ID；当前界面不提供 ID 重命名。

“撤销/重做”覆盖剧情字段、增删和连接操作。删除节点不会自动替其他节点选择新目标，入边须手动修复。入口来自 `game.json`，编辑器显示为只读，也禁止删除入口节点；修改入口仍需编辑该文件并重新读取。

节点位置仅按作品 ID 存在本机浏览器存储中，不写 `story.json`，也不参与剧情撤销。剧情文件可独立版本管理，不包含作者电脑的画布坐标。

## 动效与预览

右侧可为每个节点配置无动效、淡入或上移入场，以及 0–10000 毫秒时长。视频节点作用于视频容器，选择/结局作用于剧情界面。系统启用减少动态效果时直接呈现终态。

草稿预览支持从头开始、重播当前节点和保留进度。选中节点还可点击“从该节点预览”。保留进度要求当前视频内容兼容，修改了当前视频就用重播策略。完整规则见 [动态更新 API](dynamic-content-api.md)，代码自定义淡出、取消、时间触发见 [动效 API](effects-api.md)。

这里的画布编辑剧情连接，尚不编辑视频剪辑、多轨时间轴或 React UI 布局。基础动效不是两段视频的交叉溶解；复杂演出可在作品代码中组合动效接口。

## 保存冲突与退出

“保存剧情”校验候选和实际素材，并检查初次读取的磁盘版本。如果其他程序修改了同一个 `story.json`，保存会拒绝覆盖并保留当前草稿。先记录需要保留的修改，再重新读取并合并，不反复强行保存旧内容。

“重新读取”会替换草稿；关闭编辑器会销毁它。存在未保存修改时显示确认。预览草稿则保留草稿，不等于保存。关闭整个窗口也有未保存保护；务必确认“已与磁盘同步”后再退出。

## 模块与 API

| 目录 | 职责 |
| --- | --- |
| `src/editor/state/` | 不完整输入草稿、历史、磁盘版本和异步操作 |
| `src/editor/graph/` | 节点图、坐标与连线呈现 |
| `src/editor/inspector/` | 按节点类型编辑字段 |
| `src/editor/components/` | 制作界面的公共字段控件 |
| `src/authoring/story/` | 供代码调用的严格节点草稿 API |
| `src/authoring/storage/` | 文件校验与版本安全保存 |
| `src/desktop/authoring/`、`ipc/authoring.ts` | 固定当前作品的制作服务与开发态 IPC |

开发态 `window.adv.authoring` 提供 `read()`、`validate(story)`、`save({story, expectedRevision})`、`preview(story)`。读取、校验、保存返回 `{ok:true,value}` 或 `{ok:false,error}`；预览返回 `GameLoadResult`，交给现有预览控制器管理应用与素材版本。调用方不能传入任意本机目录。发布态没有该桥接对象或写入 IPC。
