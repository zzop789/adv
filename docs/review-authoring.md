# 制作功能与模块拆分 Review

日期：2026-10-02。范围：制作 API A–D、功能目录拆分、动态内容更新、统一动效和可视化流程编辑器。

## 交付范围

- 草稿与文件保存分别放在 `authoring/story`、`authoring/storage`；桌面环境、内容加载、媒体服务与 IPC 分开。
- 剧情执行、会话、更新策略和数据契约分别放在 `runtime/story`、`session`、`content`、`model`。
- 视频与动效分别放在 `presentation/video`、`effects`；界面管理与剧情绑定分别放在 `ui/manager`、`player`。
- 编辑器拆为状态、画布、检查器和字段组件，渲染入口只组装播放器及开发工具；原导入路径保持短兼容导出。
- `applyContent` 提供三种应用策略；`EffectsPlayer` 与 `CueScheduler` 提供动效控制和媒体时间触发；开发态编辑器可以保存剧情或预览未保存草稿。

代码组织规则已固定在 [AGENTS.md](../AGENTS.md)。使用入口见 [编辑器教程](visual-editor-guide.md)、[动态更新 API](dynamic-content-api.md) 和 [动效 API](effects-api.md)。

## 审查修复

| 问题 | 修复与验证 |
| --- | --- |
| 保留进度使 visit 变化，关闭编辑器或设置后不能恢复原播放 | 恢复意图绑定物理视频 source，换源时失效；保留策略仍可恢复 |
| 更新作品信息时重新绑定 presenter，丢失设置实例和音量同步 | 保持同一个 presenter，通过 `updateGame` 刷新作品参数 |
| 订阅器抛错让已提交内容被误判失败，可能释放正在使用的新素材版本 | 隔离状态通知异常；继续通知其他订阅器，内容提交结果不倒退 |
| 安装候选时同步销毁预览宿主，仍发布已释放候选 | 安装后重新检查生命周期与请求代次 |
| 异步保存期间新编辑被误标为已保存 | 保存采用提交快照作为基线；操作同步互斥，保存失败保留草稿 |
| 选择/结局界面首次挂载时目标 DOM 尚未出现，漏掉入场效果 | 动效挂载跟随实际界面实例；真实 Electron 检查动画存在 |
| 旧素材版本在目录被替换为外部链接后可能读取作品外文件 | 每次请求复查真实路径，使用同一个已校验文件句柄流式读取 |
| 发布启动时计算整部作品的视频指纹会增加等待 | 指纹只用于开发态动态兼容检查，普通发布启动不读取全量视频计算哈希 |
| 打包输出的 HTML 触发开发窗口刷新，干扰未保存草稿 | 开发监听排除 dist、release 和 test-results，制作服务只监听真实源码 |

## 验证方法

单元测试覆盖严格草稿 API、编辑器不完整输入、撤销重做、保存冲突、候选校验、文件指纹、版本映射、状态事务、旧回调、动效生命周期、时间触发及弹窗恢复。

`test:editor` 和 `test:preview` 使用临时作品副本启动真实 Electron 与本机 Vite，两者使用同一开发端口，应顺序执行。它们验证编辑器完整操作和动态更新，正式演示剧情与素材不被修改。另用两套作品的构建版和便携 EXE 验证播放器、分支与设置，并检查发布态没有 authoring 桥接和编辑器脚本。

最终结果：

| 验证 | 结果 |
| --- | --- |
| `npm run check` | 类型检查及 160 项测试通过 |
| `npm run test:editor` | 节点图、三类节点、选项/动效、历史、草稿预览、保存冲突、未保存保护、拖动缩放、保留视频进度及入口动效通过 |
| `npm run test:preview` | 同会话重载、候选失败保留、修复重试、保留进度和旧素材版本释放通过 |
| 两部作品的 `test:smoke -- --built` | 播放、两条分支/结局、设置、全屏、中文素材路径、坏视频和无效剧情通过 |

| 两部作品的 `test:smoke -- --packaged` | 最终 EXE 离线回归通过；authoring 桥接和编辑器脚本未进入玩家包 |

真实 Web Animations 另验证了暂停恢复、同目标替换取消、淡出保留终态、清理恢复原样式、保留原 transform 和系统减少动态效果设置。已目视检查 `test-results/editor.png`，节点图和字段面板显示正常。

开发验证中出现过一次保存状态等待超时，完整重跑没有复现；脚本已保留失败页面内容诊断。目前没有定位到可复现的保存缺陷，不能把该次超时当作已经解释清楚的产品问题。

## 已知边界

制作编辑器仅在 `npm run dev` 中提供，保存范围是 `story.json`。入口与构建信息仍在 `game.json`，素材路径仍在 `assets.json`，UI 布局仍为 React/CSS。不是多轨视频剪辑器或 UI 布局编辑器。

素材版本固定的是映射，不复制视频字节。不要原位覆盖正在播放的物理文件；替换素材应新增文件再改映射。开发态首次计算大量大视频的指纹仍需读取时间，后续按文件元数据缓存。

候选读取、校验或兼容检查失败会保留旧播放。内容已提交后的解码失败停留新节点，显示错误并允许重试，不回滚旧片。动效不推动剧情；当前没有双视频交叉溶解。

外部编辑器不共享进程内保存队列，版本检查不能作为跨进程文件锁。标题菜单、设置持久化、节点存档和混合 ADV 玩法仍属后续阶段。
