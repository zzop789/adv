# 阶段 3 审查与验证记录

日期：2026-10-02。范围：从阶段 1 播放器扩展到阶段 2 剧情闭环和阶段 3 两作品生产流程。

## 交付结果

《雾港》和《余光来信》各包含三段不同视频、一次双选项分支、两个结局、独立 UI 与图标。两者使用相同的 `StoryRunner`、`StorySession` 和 `VideoController`；构建时选择作品 UI，成品不包含另一部作品的内容。

Windows x64 便携包包含 Electron，完整文件夹可以独立交付。程序名分别为 `FogHarbor.exe` 和 `AfterglowLetter.exe`。作品信息、入口、剧情、素材映射和打包命令见 [README](../README.md)。

## 审查发现与修复

采用模块实现后的交叉代码审查，再结合真实 Electron 和 Windows EXE 验证。下列问题均已修复，当前阶段 3 范围内无已知阻塞项。

| 问题 | 触发与影响 | 修复与验证 |
| --- | --- | --- |
| 旧视频暂停事件污染当前状态 | 旧源的排队 `pause` 在新源播放后抵达，界面可能错误显示暂停 | 事件处理核验 `video.paused`；回归测试覆盖旧 `pause` / `ended` |
| 同步回调重开导致视频与节点错位 | `load()` 通知观察者，观察者立即重开，外层加载仍覆盖新视频 | 独立加载代次与播放请求代次，通知后再次检查；覆盖加载、暂停、拖动、重播、销毁与旧异常 |
| 配置允许的素材未被打入包 | 素材位于作品其他目录，原校验允许但打包只复制 `media/` | 规范化路径后要求视频与图标位于 `media/`；拒绝符号链接，新增内容边界测试 |
| 窗口图标忽略配置 | 修改 `build.icon` 后 EXE 图标变了，窗口仍取固定文件名 | 窗口从校验后的配置设置图标；两作品 EXE 图标的六档资源已核验 |
| 单作品打包漏查身份冲突 | 分别打包两部相同 `appId` 的作品，会共用应用数据目录 | 对整个作品注册表检查选中作品的 `appId` 与 EXE 名，新增单作品冲突测试 |
| 书信界面纵向溢出 | 标题、信笺和按宽度撑开的影片超过窗口可用高度 | 使用视口内弹性布局，矮窗口压缩留白；默认与最小窗口逐状态检查 |
| Windows 短暂占用导致发布失败 | 完成构建后目录改名偶发 `EPERM` | 针对 `EPERM` / `EBUSY` 有界重试；保留 staging 发布与旧产物恢复流程 |

剧情节点使用 `visitId` 拒绝过期输入，播放器使用 `sourceId` 拒绝旧源完成与错误。重试当前节点也分配新的播放代次。媒体失败不视为剧情完成，选择和结局保留末帧。

## 验证记录

环境：Windows x64，Node.js 24.19.0，Electron 44.5.1。依赖版本由 `package-lock.json` 固定。

| 验证 | 结果 |
| --- | --- |
| TypeScript 类型检查与行为测试 | 45 项测试通过，覆盖剧情、播放器、路径、协议、构建输出与身份冲突 |
| 两作品实际构建 | 均成功，非法内容在发布前被校验阻止 |
| 两作品构建副本的真实 Electron 验证 | 均通过离线播放、暂停、拖动、音量、重播、双分支双结局、重新开始、重复点击、过期事件、全屏与退出全屏 |
| 素材与错误检查 | 中文及空格文件名替换通过；缺失素材、损坏分支、损坏素材重试和无效跳转均显示错误，未跳过剧情 |
| 布局与截图复核 | 两作品在 1280×840 与 900×680 窗口中完成播放、选择、结局检查，主要内容与操作均可见且无滚动溢出 |
| CLI 入口 | 两作品的 `start`、`start:built`、`dev` 共六次隐藏启动验证通过，作品参数与 UI 别名一致 |
| 打包及资源检查 | 两个包成功生成；EXE 产品名、文件名、六档图标、目标作品隔离和第三方许可证检查通过 |
| 实际发布 EXE | 直接从两个发布包启动，使用不同工作目录且关闭浏览器网络，双分支双结局、播放操作、窗口布局及应用数据隔离均通过 |

行为测试使用 Node.js 测试运行器；窗口验收使用 Playwright 启动真实 Electron。故障注入在 `test-results/` 副本中进行，不修改作品源内容。截图同样保存在该目录；验证脚本为 `tools/smoke.mjs`，支持 `--game`、`--built` 和 `--packaged`。

## 当前边界

- 尚无存档与设置持久化，属于阶段 4；当前应用数据目录已按作品隔离。
- 当前交付未签名的便携文件夹，分发时必须保留整个目录；安装向导与签名未加入本阶段。
- 样例视频均为 6 秒 VP8 无声动画。已验证视频播放和音量属性；真实影视素材的音轨、长片性能、其他编码及目标硬件仍需按实际素材验收。

- `rcedit` 仅用于构建阶段写入 EXE 资源，已锁定版本并实测；上游已归档，后续依赖维护需评估替代方案。
- 当前只验证 Windows PC，未开展手机或网页交付。
